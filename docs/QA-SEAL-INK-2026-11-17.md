## 一、根因

### ① 中央断裂：裂口是"从块里面长出来的"

`cuts()` 负责往 mask 里挖"缺墨"：2~3 条 **path**（0.85~1.45px 宽、opacity 0.8~1.0 的纯黑）
+ 1~3 个针孔圆。旧版**只有第一条**从盒子边界起笔，其余全部从**随机内部点**起步，
方向顺着长轴（`longAxis`），长度 `shortSide × (0.14~0.24)`，还有 25% 概率分叉
（再长 0.18~0.40 倍）。

在 37px 宽的长牌上，一条 8.9px 的纵向黑线 + 分叉 = 把块面纵劈成两半；
50×88 的短名上，那条从边界直插中央的线同样像"撕开的断口"。

另外 mask 里的针孔层 `#holes` 铺的是**整块** rect（`feTurbulence` 阈值离散化后
约 5% 面积被挖），中央因此遍布麻点 —— 那也是"碎"。

### ② 碎点太多、且被画布切掉一半

- 数量：主点 8~11 个 × (28% 拖痕 / 否则 1 + 50% 概率 1~2 颗簇点)
  → 单块图元期望 ≈ **14.6**，峰值可到 33。
- 站位：外界写死 `band − 0.4`（band = 10px），圆心最大 9.6px，而大点半径 3.6px
  → **内沿顶进牌面 3.2px**；同时拖痕 `rx` 可达 8.6px 且随机角度旋转，
  很大一部分被 viewBox 裁成半月形/直边。一圈"切边点"比少放几个点还碎。

## 二、改法

### 墨块（`inkSVG` / `cuts`）

| 项 | 改前 | 改后 |
|---|---|---|
| 裂口起点 | 第 1 条边界，其余随机内部 | **一律边界**（外扩 0.8px 起笔） |
| 方向 | 第 1 条朝中心，其余顺长轴 | 朝块内的法向 ± 0.45rad（不许拐向中央） |
| 中央保护带 | 无 | 距中轴 **< 短边 × 0.26**（≈ 中间 52%）不许进入，越界就地收口 |
| 贴短轴的两条边（竖牌的上/下） | 任意位置下口 | 只在两侧边带内下口 |
| 针孔（mask `#holes`） | 整块 rect | **只在两侧边带**（`shortSide/2 − 26%`），中央只留 grain 的颜色层次 |
| 针孔（cuts 里的小圆） | 全块随机 | 只落边带，抽 8 次不中即放弃 |

于是中轴沿线恒是一条完整的红，边缘照样有撕口 —— 只是撕不到中间。

### 碎点（`specksSVG`）

| 项 | 改前 | 改后 |
|---|---|---|
| 主点 | 8~11 | **5~7** |
| 大点占比 | 0.28 | 0.40（少而清楚） |
| 簇点 | 50% 概率 1~2 颗 | 30% 概率 1 颗 |
| 拖痕 | 28%，随机角度、`rx` 至 8.6px | 15%、**每块最多 1 条**、**长轴平行于牌边**（`rx`=沿边、`ry`=带宽） |
| 总图元 | 期望 ≈14.6 | **硬预算 8**（`out.length < 8`） |
| 站位 | 圆心 3.7~9.6px（内沿压牌） | `thick+0.9 ~ band−0.4−thick`（整颗不压牌、不出画布） |
| 沿边两端 | `t = 0.05~0.95`（角落被切） | 两头各留 `along+0.6`，角落那颗也是完整的圆 |

散沫（簇点）坐标额外 clamp 进画布，杜绝角落半颗。

## 三、结果

探针矩阵：**6 种牌面尺寸 × 20 个种子 = 120 块**（30×60 预览 / 37×418 超长 /
44×132 三字 / 50×88 两字 / 56×260 长名 / 90×40 横牌兜底）。

```
33 项断言 · 0 失败
```

| 指标 | 改前 | 改后 | 判据 |
|---|---|---|---|
| 中央露底（短轴中间 30%、长轴两头各留 10%） | 3.7%~6.25%* | **0.00%** | ≤ 0.5% |
| 中央带最低 alpha | — | **1.000** | 反解后无透底 |
| 中央"整行/整列全空"最长连续 | — | **0px** | ≤ 1px |
| 牌面墨色覆盖 | 0.76~0.86 | 0.76~0.86 | ≥ 0.72 |
| 边带墨色覆盖 | 0.30~0.50 | 0.30~0.50 | 0.22~0.60（有撕口但不啃空） |
| 碎点图元 | 期望 14.6（峰可到 33） | **6~8，均 7.75** | 单块 ≤ 9、均值 ≤ 8.0 |

\* 改前那组数是把针孔恢复成整块 rect 后实测的（`max=6.25% seed=1`）——
旧的内部裂口只会更糟，不会更好。

### 负向验证（证明断言不是摆设）

| 故意改坏 | 结果 |
|---|---|
| 针孔 rect 恢复整块 | **6 个尺寸全红**：中央露底 3.71%~6.25% |
| 中央保护带从 0.26 收到 0.02 | **3 个尺寸红**：中央露底 0.81%~1.22% |

两次改坏都精确打在"中央"这一条上，改回即绿。

## 五、边界

- **裂口变浅**：中央 52% 保护之后，37px 宽的长牌左右各只剩 ~8.9px 的边带可咬，
  撕口比改前短。这是"中间完整"的必然后果，不是缺陷。
- **擦痕不再乱角度**：为了不被 viewBox 裁成直边，拖痕长轴平行于牌边，
  观感更像"蹭在牌边上的一道"，而不是斜飞出去的墨丝。
- 碎点上限是**图元数**硬预算 8（含散沫小点），视觉上的主点通常 5~7 颗。
